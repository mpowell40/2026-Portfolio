01 · About

Defending systems by understanding how they break

I focus on security operations and detection engineering. That led me to Georgia Tech, where I'm finishing my M.S. in Cybersecurity (Cybersecurity & Privacy track) in December 2026.

Years of teaching computing to high school students also taught me to document and explain technical findings clearly, which matters every time an alert gets escalated.

AI Agent Security In progress

MCProxy: Policy Enforcement Proxy for AI Agent Tool Calls

Cyber Security Practicum (CS 6727) · Georgia Institute of Technology

Role fit AI Security · Security Engineering · Research

  • Designed and built a network-level reverse proxy that intercepts Model Context Protocol (MCP) tool calls between AI agents and tool servers, enforcing security policy before unsafe actions like data exfiltration or unauthorized file and command access can execute.
  • Implemented a two-tier enforcement engine in Python that pairs stateless boundary checks with a stateful DFA to detect malicious multi-step tool-call sequences. Building an attack-scenario test suite to measure detection rate, false positives, and latency overhead.
