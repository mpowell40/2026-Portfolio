# Mekhel Powell, Cybersecurity Portfolio

Personal site for Mekhel Powell, M.S. Cybersecurity candidate at Georgia Tech (Dec 2026).

Live: https://mpowell40.github.io/

## Stack

Plain HTML, CSS and JavaScript. No build step and no frameworks.

- `index.html`: all content (about, experience, projects, skills, education, contact)
- `style.css`: deep-space theme, glass cards, responsive layout
- `script.js`: parallax starfield with shooting stars, custom cursor, scroll reveals, typed roles, count-up stats, honeypot log feed

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Push to a GitHub repo named `mpowell40.github.io`, then in **Settings → Pages** set the source to the `main` branch, root folder.
